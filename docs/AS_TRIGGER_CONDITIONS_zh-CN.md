# ActiveScene 视频触发条件 分析

## 触发规则

- 素材索引包含 73 条 AS 记录，按素材 ID 去重后共有 65 个视频。
- 49 个视频带有上下文条件，另外 16 个是无条件通用视频。
- 同一视频列出的多个条件是“或”（OR），满足任意一个即可进入候选池。
- 条件匹配只代表视频可以参与加权随机选择，不保证条件出现后立即播放。
- 匹配的视频会和无条件视频一起选择，并受到最近播放记录与长期播放次数的影响。
- AS 素材没有使用 `dependencies` 或 `exclusions`；它们的限制全部来自 `info`。

## 天气条件

| 条件 | AS 视频 |
|---|---|
| 冰冻、下雪或冬季 | `101_AS001` |
| 下雪、冰冻，或春/秋/冬季 | `102_AS025` |
| 晴天、无云，或夏季 | `102_AS026` |
| 暴风雨 | `103_AS042` |
| 大风 | `103_AS043` |
| 下雨或暴风雨 | `103_AS045` |
| 大雾 | `104_AS064` |

通过 Open-Meteo 获取天气，并按以下规则转换：

- WMO `0–1`：`clear`；白天同时为 `sunny`
- WMO `45、48`：`foggy`
- WMO `51–55、61–65、80–82`：`rainy`
- WMO `56、57、66、67`：`icy` 和 `rainy`
- WMO `71–77、85、86`：`snowy`
- WMO `95–99`：`stormy`
- 风速至少 `29 km/h`：额外加入 `windy`

天气功能关闭、没有有效城市或天气缓存失效时，纯天气条件视频不会进入候选池；同时带季节条件的视频仍可能通过季节匹配。

## 每日作息条件

| 本地时间 | 作息条件 | AS 视频 |
|---|---|---|
| 05:00–09:59 | 早晨 `morning` | `102_AS018`, `102_AS029` |
| 10:00–11:59 | 早午餐 `brunch` | `104_AS055` |
| 12:00–13:59 | 午餐 `lunch` | `101_AS004` |
| 14:00–17:59 | 下午 `afternoon` | `103_AS033` |
| 18:00–20:59 | 晚餐 `dinner` | `101_AS004`, `103_AS044` |
| 21:00–22:59 | 睡前 `bedtime` | `102_AS017`, `103_AS048` |
| 23:00–04:59 | 深夜 `lateNight` | `103_AS034`, `103_AS048`, `104_AS062` |
| 07:00–10:29 | 同时叠加“上学” `goingToSchool` 和“上班” `goingToWork` | `103_AS037` |

通勤条件会与原本的 `morning` 或 `brunch` 条件同时存在，所以 `103_AS037` 会加入加权候选池，但不会挤掉其他早间素材；同时命中“上学”和“上班”也不会重复加权。作息条件命中的基础权重为普通素材的 3 倍，同时仍受最近播放冷却和长期播放次数平衡约束，不会每次都出现。

## 宽泛时段条件

| 本地时间 | 时段条件 | AS 视频 |
|---|---|---|
| 12:00–17:59 | 下午 `afternoon` | `103_AS039` |
| 18:00–22:59 | 晚上 `evening` | `103_AS039`, `103_AS041`, `104_AS053`, `104_AS057` |
| 23:00–05:59 | 深夜 `lateNight` | `103_AS039`, `103_AS041`, `104_AS057`, `104_AS070` |

这些时段条件与节日条件也是“或”的关系。因此：

- `104_AS057` 不只在农历新年、元旦或美国独立日出现，普通晚间和深夜也可以出现。
- `103_AS039` 不只属于万圣节，从普通下午开始也可以出现。
- `103_AS041` 不只属于 Peanuts 首篇漫画纪念日，普通晚间和深夜也可以出现。
- `104_AS053` 不只属于跨年夜，普通晚间也可以出现。
- `104_AS070` 不只属于元旦，普通深夜也可以出现。

## 当前没有用于 AS 的上下文

虽然播放上下文能够计算以下信息，但目前没有 AS 视频使用它们：

- 整点 `onTheHour`
- 午夜 `midnight`
- 正午 `midday`
- 日出 `sunrise`
- 日落 `sunset`
- 月相条件

这些上下文可能会用于其他素材类型，例如访客、天气效果或场景调色板。
